## Featured: GoGoIdea

**[GoGoIdea](https://github.com/herominutes/gogoidea)** is a Claude Code plugin with one command, `/hero:gogoidea`, and two evidence-based go/no-go checkpoints:

- **Idea:** what should I build? It collects public evidence, judges ideas with isolated reviewers, and is allowed to say "nothing survived".
- **Gate:** should we close this sprint and ship? Ten review lenses, severity levels, and a rule that one critical issue means No-Go however good the average looks.

What makes it more than a prompt:
- Scripts verify quotes, files, lines and counts instead of trusting the model.
- Reviewing and deciding are separate roles.
- Testing found and fixed ten defects in my own design, and the [case study](https://github.com/herominutes/gogoidea/blob/main/docs/CASE-STUDY.md) lists each one.

## How I build AI products

1. **Start with the user's decision, not the model.** AI is a capability, not the product.
2. **Evidence is checked, not trusted.** Verify with code wherever you can.
3. **Evaluation is a product feature.** Build the test before you trust the output.
4. **A "no" is a valid answer.** Say what was not covered.
5. **Guardrails are architecture.** Privacy and safety are design decisions, not afterthoughts.
